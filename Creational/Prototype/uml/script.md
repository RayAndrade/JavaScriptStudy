# 🌟 Prototype — Participants (for JavaScript Students)

## **Prototype**

* Defines the method for cloning itself into a new object.
* Stores the default state shared by its copies.
* Lets objects create new versions without classes.

## **ConcretePrototype**

* Implements the cloning method from Prototype.
* Copies its internal state into a new object.
* Produces independent duplicates with similar behavior.

## **Client**

* Requests new objects by cloning a Prototype.
* Avoids using `new` to create many similar objects.
* Easily changes which Prototype it clones.
