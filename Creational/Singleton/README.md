# 🌟 Singleton — Participants (for JavaScript Students)

## **Singleton**

* Ensures only one instance of this class ever exists.
* Provides a global access point to that single instance.
* Creates the instance lazily when first requested.

## **Client**

* Requests the single instance from Singleton.
* Never creates the object directly with `new`.
* Uses the same shared instance throughout the program.
